# Как дополнять этот список

Спасибо. Правила короткие.

## Что подходит

- Инструменты **с CLI или HTTP API** — то, чем агент может пользоваться сам.
  Сервис с одним веб-интерфейсом агенту бесполезен.
- Скиллы, субагенты, хуки, MCP-серверы, полезные исследователю.
- Документация и статьи — только первоисточники.
- Воркфлоу, которые вы правда прогоняли на своей работе.

## Что не подходит

- Ссылки без проверки. Если не открылось — не добавляем.
- Пересказы документации вместо самой документации.
- Реклама и «подборки промптов».
- Выдуманные цифры: число звёзд, «в 10 раз быстрее», «лучший инструмент».
- Копии чужих репозиториев. Ссылка или, если очень нужно и лицензия MIT/Apache,
  подмодуль.

## Формат записи

Одна строка на пункт:

```markdown
- [Название](ссылка) — зачем это исследователю, одно-два предложения. Лицензия, если репозиторий.
```

Английские названия инструментов оставляем как есть. Всё остальное — по-русски.

## Перед отправкой PR

1. **Проверьте, что ссылка открывается.**

   ```bash
   curl -sS -o /dev/null -w "%{http_code} %{url_effective}\n" -L "<url>"
   ```

   Ждём `200`. Редирект на другой сайт — подозрительно, посмотрите, куда ведёт.
   Для GitHub удобнее `gh api repos/<owner>/<repo>`: заодно увидите лицензию и
   дату последнего коммита.

2. **Проверьте лицензию**, если добавляете репозиторий. Нет лицензии — так и
   напишите: «не указана».

3. **Не пишите про то, чего не пробовали.** Лучше одна строка «не проверяли»,
   чем уверенное описание из README автора.

4. **Соблюдайте тон.** Без восторгов, без «революционный» и «незаменимый».
   Что делает, кому полезно, чем ограничено.

## Чего мы избегаем сознательно

- **Чисел, которые стареют.** Звёзды, число скиллов, версии. Через месяц это
  враньё.
- **Обещаний.** «Агент напишет вам статью» — нет, не напишет.
- **Секретов и приватных данных** в любом виде.

## Структура репозитория

| Куда | Что |
|---|---|
| `01-philosophy/` … `07-other-lists/` | разделы, по `README.md` в каждом |
| `skills/` | наши примеры `SKILL.md` и ссылки на чужие |
| `templates/` | заготовки для исследовательского проекта |
| `README.md` | оглавление, «старт за 30 минут», уровни |

Добавляете новый раздел — не забудьте про оглавление в корневом `README.md` и
про навигационные ссылки внизу соседних разделов.
