# Скиллы

[← к оглавлению](../README.md)

Скилл — папка с файлом `SKILL.md`: многошаговая инструкция, которую агент
подгружает только тогда, когда она нужна. Что это такое и как устроено —
в [03. Механики](../03-agent-basics/README.md#скиллы).

Здесь: готовые скиллы для исследователя (наши, простые, читаемые за минуту) и
ссылки на чужие.

---

## Наши примеры

Два скилла, написанные так, чтобы их можно было прочитать целиком и переделать
под себя. Это учебные образцы, а не готовый продукт — берите как заготовку.

| Скилл | Что делает |
|---|---|
| [`lit-note`](lit-note/SKILL.md) | Делает структурированную заметку по прочитанной статье: выжимка фактов, без интерпретаций и без домыслов. Основа для будущего related work |
| [`check-citations`](check-citations/SKILL.md) | Сверяет `\cite` в тексте с `.bib` и проверяет каждый DOI через Crossref. Главная защита от выдуманных ссылок |

### Как поставить

Скопируйте папку скилла в одно из двух мест:

```bash
# личный — доступен во всех ваших проектах
cp -r skills/lit-note ~/.claude/skills/

# проектный — едет вместе с репозиторием, доступен соавторам
mkdir -p .claude/skills && cp -r skills/lit-note .claude/skills/
```

Перезапустите сессию. Проверить, что подхватилось — набрать `/` и посмотреть
список, или вызвать напрямую: `/lit-note`.

Для Codex порядок тот же, поле `description` играет ту же роль:
[Build skills](https://learn.chatgpt.com/docs/build-skills).

### Как переделать под себя

1. Откройте `SKILL.md`, поменяйте шаги под свою область и свой формат заметок.
2. Перепишите `description` — по нему агент решает, когда скилл уместен.
   Пишите конкретно, с триггерами: не «про статьи», а «когда просят
   законспектировать статью или добавить работу в обзор литературы».
3. Оставьте `disable-model-invocation: true`, если не хотите, чтобы агент
   запускал скилл по своему усмотрению.

Правила оформления — [Skill authoring best
practices](https://platform.claude.com/docs/en/agents-and-tools/agent-skills/best-practices).
Формат — открытый стандарт: [agentskills.io](https://agentskills.io),
[спецификация](https://agentskills.io/specification).

## Прежде чем ставить чужой скилл

`SKILL.md` — это инструкции, которые ваш агент выполнит, и права, которые он
себе выдаст. Читайте целиком, особенно:

- **`allowed-tools`** — что скилл разрешает агенту без вашего подтверждения;
- **скрипты в папке скилла** — что именно запускается;
- **сетевые вызовы** — куда уходят ваши файлы.
