# Заметка по статье

Цель — выжимка фактов, по которой потом можно будет написать related work, не
перечитывая статью. **Не интерпретация, не пересказ аннотации, не оценка
качества.** Факты и адреса фактов.

## Шаги

1. **Получи текст.** Если на входе PDF — сначала конвертируй:

   ```bash
   docling <файл.pdf> --to md --output papers/
   ```

   Если docling не установлен, скажи об этом и остановись. Не пытайся
   пересказать статью по заглавию.

2. **Найди метаданные.** DOI или arXiv ID — из текста статьи. Затем сверь через
   Crossref:

   ```bash
   curl -s "https://api.crossref.org/works/<DOI>"
   ```

   Заглавие, авторы, год и издание бери **из ответа API**, а не из PDF: в PDF
   часто препринтная версия с другими выходными данными.

3. **Заполни заметку** по шаблону ниже. Файл:
   `notes/literature/<первыйавтор><год>-<два-три-слова>.md`

4. **Правила заполнения:**
   - Все числа — дословно из статьи, с указанием, откуда (раздел, таблица,
     рисунок).
   - Чего в статье нет — пиши `не указано`. Не выводи, не оценивай, не
     подставляй типичное значение.
   - Цитаты дословные — в кавычках, с указанием раздела.
   - Своё мнение — только в блоке «Мои пометки», и помечай, что оно твоё.

5. **В конце покажи** список того, что осталось `не указано`. Это и есть
   слабые места работы, и они пригодятся при рецензировании и воспроизведении.

## Шаблон

```markdown
# <Заглавие>

- **Ключ:** <ключ цитирования из refs.bib, или «нет в bib»>
- **DOI:** <doi> · **Год:** <год> · **Издание:** <журнал/конференция>
- **Авторы:** <первые три и др.>
- **Файл:** <путь к PDF/markdown>

## Задача
Какой вопрос ставят. Одно-два предложения.

## Данные
Источник, размер выборки, как собраны, доступны ли публично.

## Метод
Что именно делают. Ключевые параметры с числами.

## Результаты
Главные числа с указанием таблицы/рисунка. Единицы измерения обязательны.

## Что авторы признают ограничением
Дословно или близко к тексту, со ссылкой на раздел.

## Отношение к нашей работе
Чем это отличается от того, что делаем мы. Конкретно.

## Не указано в статье
- ...

## Мои пометки
(мнение агента, требует проверки человеком)
```

## Чего не делать

- Не заполняй поля по догадке, даже если догадка почти наверняка верна.
- Не пиши «авторы показали, что…», если в статье этого нет дословно.
- Не оценивай статью как хорошую или плохую — это работа человека.
