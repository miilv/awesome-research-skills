# Проверка ссылок

Выдуманная или искажённая ссылка — самый дорогой отказ в работе с агентом.
Этот скилл проверяет всё, что можно проверить механически.

**Ничего не исправляй сам.** Задача — отчёт. Решения принимает человек.

## Шаги

### 1. Ключи в тексте против .bib

Собери все ключи из `\cite`, `\citep`, `\citet`, `\citealp` и подобных команд
во всех `.tex` проекта. Собери все ключи `@article{...}` и т.п. из `.bib`.

Выведи два списка:
- **Нет в .bib** — процитировано, но записи нет. Сборка сломается.
- **Не процитировано** — запись есть, в тексте не используется. Обычно мусор
  после правок, но проверь: возможно, утверждение потерялось при редактуре.

### 2. Каждую запись с DOI — через Crossref

Для каждой записи `.bib`, у которой есть поле `doi`:

```bash
curl -s -H "User-Agent: check-citations (mailto:<email из AGENTS.md>)" \
  "https://api.crossref.org/works/<DOI>"
```

Сверь с тем, что записано в `.bib`:

| Поле | Критерий |
|---|---|
| DOI | резолвится, ответ 200 |
| заглавие | совпадает дословно, с точностью до регистра и пунктуации |
| первый автор | фамилия совпадает |
| год | совпадает точно |
| издание | `container-title` совпадает с `journal`/`booktitle` |

Расхождение в год или в название журнала — **не мелочь**: это типичный след
того, что запись сгенерирована, а не взята из источника.

### 3. Записи без DOI

Выпиши отдельным списком. Для препринтов arXiv проверь через arXiv API. Для
остального — отметь как «проверить вручную». Не придумывай DOI.

### 4. Отчёт

Таблицей, в таком виде:

| Ключ | Статус | Что не сошлось |
|---|---|---|
| smith2024 | ok | — |
| jones2023 | расхождение | год в .bib 2023, в Crossref 2022 |
| lee2025 | НЕ НАЙДЕН | DOI не резолвится |
| chen2024 | без DOI | препринт, проверен по arXiv |

В конце — три числа: проверено, расхождений, не найдено.

## Ограничения скилла

- Совпадение метаданных не означает, что статья говорит то, что вы ей
  приписываете. Смысловую проверку цитаты этот скилл не делает — её делает
  человек, открыв статью.
- Crossref покрывает не всё: книги, тезисы, часть трудов конференций могут
  отсутствовать. Отсутствие в Crossref само по себе не доказывает, что работы
  нет.
