# Awesome Research Skills

> Как исследователю работать с ИИ-агентами — Claude Code, Codex и им подобными.
> Не «промпты для ChatGPT», а инженерная практика: память проекта, скиллы,
> субагенты, проверяемые воркфлоу и честные грабли.
>
> Всё на русском. Названия инструментов — как есть. Каждая внешняя ссылка
> проверена на момент сборки.

**Для кого:** для исследователей, которые пока не пользуются агентами в работе
и не понимают, чем это отличается от чата с ИИ. Программистом быть не нужно —
терминал открыть придётся.

---

## Старт за 30 минут

Четыре шага. После них вы будете пользоваться агентом, а не читать о нём.

### 1. Поставьте агента (5 минут)

Один из двух, оба хороши. Нужна подписка или доступ к API.

**Claude Code** — [документация](https://code.claude.com/docs/en/overview),
[quickstart](https://code.claude.com/docs/en/quickstart):

```bash
curl -fsSL https://claude.ai/install.sh | bash   # macOS, Linux, WSL
```

**Codex CLI** — [документация](https://learn.chatgpt.com/docs/codex/cli):

```bash
curl -fsSL https://chatgpt.com/codex/install.sh | sh   # macOS, Linux
```

На Windows работает и то и другое — смотрите инструкции по ссылкам; проще
всего через WSL.

### 2. Откройте проект и просто посмотрите (5 минут)

Перейдите в папку с вашей статьёй или кодом анализа. Важно: **это должен быть
git-репозиторий.** Если ещё нет — `git init`, `git add -A`, `git commit`.

Запустите агента в режиме, где он ничего не может сломать:

```bash
claude --permission-mode plan     # или: codex
```

И спросите что-нибудь настоящее:

> Прочитай структуру проекта и скажи, что здесь происходит. Ничего не меняй.

Это и есть главное отличие от чата: он читает ваши файлы сам.

### 3. Напишите память проекта (15 минут)

Это тот шаг, который отделяет «агент бесполезен» от «агент — соавтор».
Не пропускайте его.

```bash
# Claude Code сделает черновик сам:
/init
```

Потом откройте получившийся `CLAUDE.md` (или создайте `AGENTS.md` из
[шаблона](templates/AGENTS.md.example)) и допишите то, чего агент знать не мог:
чем вы занимаетесь, какими командами всё собирается, что трогать нельзя.

Пять строк, написанных руками, здесь стоят больше, чем пятьдесят
сгенерированных. Что писать и чего не писать — [раздел 02](02-memory/README.md).

### 4. Дайте первую настоящую задачу (5 минут)

Не «покажи, что ты умеешь», а что-то из сегодняшней работы. Например:

> Прочитай `paper/sections/intro.tex` и выпиши все утверждения, у которых нет
> ссылки. Списком, с номерами строк. Ничего не правь.

Или:

> Собери PDF статьи через latexmk и покажи все warning'и, которые стоит
> починить перед подачей.

Или:

> Проверь, что все ключи `\cite` из `paper/` есть в `paper/refs.bib`, и наоборот.

Дальше — по [воркфлоу](05-workflows/README.md).

## Три уровня

### Новичок — первая неделя

Цель: агент читает ваш проект и делает простые проверяемые вещи.

- [ ] Поставили Claude Code или Codex
- [ ] Проект под git, коммитите перед каждой сессией
- [ ] Работаете в режиме `plan`, смотрите `git diff` перед каждым коммитом
- [ ] Написали `CLAUDE.md` / `AGENTS.md` — руками, на полстраницы
- [ ] Прочитали [01. Философию](01-philosophy/README.md) и [02. Память](02-memory/README.md)
- [ ] Сделали хотя бы одну настоящую задачу: сборка PDF, проверка ссылок,
      аудит данных

Чего не делать: не просите написать статью, обзор литературы или Discussion.
Получите гладкий текст с выдуманными ссылками.

### Уверенный — первый месяц

Цель: агент встроен в вашу работу над статьёй.

- [ ] Настроили [разрешения](03-agent-basics/README.md#разрешения-и-песочница):
      что можно без спроса, что запрещено наглухо
- [ ] Числа в статье подставляются из `results/`, а не набираются руками
- [ ] Ссылки проверяются через Crossref — механически, каждая
- [ ] Завели [журнал решений](02-memory/README.md#2-журнал-решений) и
      [лог экспериментов](02-memory/README.md#4-лог-экспериментов)
- [ ] Прогнали свою статью через [саморецензию](05-workflows/README.md#3-рецензия-своей-статьи-до-подачи)
      до подачи
- [ ] Прочитали [06. Грабли](06-pitfalls/README.md) и знаете политику своей
      площадки по ИИ

### Свои скиллы и субагенты — дальше

Цель: ваши личные процедуры записаны и повторяются.

- [ ] Написали свой [скилл](03-agent-basics/README.md#скиллы) под то, что
      делаете регулярно
- [ ] Повесили [хук](03-agent-basics/README.md#хуки) на то, что должно
      соблюдаться железно (например, запрет записи в `data/raw/`)
- [ ] Используете [субагентов](03-agent-basics/README.md#субагенты) для
      параллельных задач — рецензии, переборы
- [ ] Подключили нужный [MCP](03-agent-basics/README.md#mcp) — Zotero,
      базу, хранилище
- [ ] Ваши скиллы и настройки лежат в репозитории и работают у соавторов

## Принципы этой подборки

1. **Только проверенные ссылки.** Каждый URL открывался при сборке. Чего
   проверить не удалось — здесь нет, даже если это известный сервис.
2. **Первоисточники, а не пересказы.** Ссылаемся на документацию Anthropic и
   OpenAI, а не на статьи о них.
3. **Никакого вендоринга.** Чужой код не копируется. Единственное исключение —
   один подмодуль на MIT-репозиторий, см. [скиллы](skills/README.md).
4. **Чужое помечено как чужое.** [Раздел 07](07-other-lists/README.md) — это
   ссылки на подборки, которые мы не проверяли, и там об этом сказано прямо.
5. **Без обещаний.** Агент не пишет за вас статью. Он делает быстрее то, что
   можно проверить, и опаснее то, что проверить нельзя.
